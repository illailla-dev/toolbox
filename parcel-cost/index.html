📦 중고거래 택배비 최저가 비교기

포털에서는 알려주지 않는 편의점 반값/알뜰택배 고유 구간 요금과 일반 CJ대한통운 위탁 편의점 택배, 규격별 우체국 택배 요금을 실시간 매칭하여 중고거래 시 가장 손해 안 보는 배송 옵션을 제안합니다.

1. 발송할 택배 물품의 조건 설정

* 의류 약 300~500g, 스마트폰 포장포함 약 400g, 전공책 약 1kg 내외입니다.

2. 배송 권역 및 목적지 선택

💡 배송 수단별 예상 요금 비교

편의점 반값/알뜰 택배 (점포 편의점 수령): 0 원

일반 편의점 대한통운 택배 (집 앞 주소 수령): 0 원

우체국 택배 (가장 빠르고 안전함): 0 원

추천 수단 적용 시 최저 택배비: 0 원

📊 중고거래 구매자 택배비 청구 가이드
