📐 CSS Clamp() 반응형 레이아웃 계산기

미디어쿼리(@media)를 촘촘히 쪼개 쓰지 않아도, 브라우저 가로폭 해상도 변화에 정비례하여 크기가 자연스럽게 스케일링되는 유동형(Fluid) 폰트 및 마진 코드를 수학적 슬로프 공식으로 정밀 도출합니다.

1. 가변 스케일링 범위 설정

* 입력 시 최대 크기 기준 모바일 최소 크기가 퍼센트(%) 비율로 자동 역산 적용됩니다.

💡 생성된 CSS 빌드 코드

clamp(24px, 5.61vw - 7.69px, 100px);

추천 선언 구조: font-size: clamp(...)

📊 반응형 크로스 브라우징 구현 가이드

* clamp() 속성은 총 3개의 인자 [최소값, 가변값(선형 슬로프), 최대값]을 가집니다. 브라우저 화면이 최소 너비보다 작아지면 최소값에 고정되고, 최대 너비보다 커지면 최대값에 고정되며, 그 사이 구간에서는 vw 단위로 선형 변환됩니다. 최신 모던 브라우저(IE 제외 전 기기)에서 완벽히 연동됩니다.
