🏦 대환대출 갈아타기 이자 계산기

기존 대출에서 더 낮은 금리의 대출로 갈아탈 때, 중도상환수수료 페널티를 제외하고도 실제로 아낄 수 있는 총 이자 비용과 매월 줄어드는 상환 금액을 비교 정산합니다.

1. 기존 보유 대출 정보 입력

* 대출 실행 후 3년이 지났다면 0%를 입력하세요.

2. 갈아탈 신규 대출 조건 입력

💡 대환대출 비교 시뮬레이션 결과

기존 대출 월 상환액 (원리금균등): 0 원

신규 대출 월 상환액 (원리금균등): 0 원

매월 절감되는 고정 지출: 0 원

예상 중도상환 수수료 비용: 0 원

대환 시 최종 순 절감 비용: 0 원

📊 대환대출 실행 타당성 가이드

* 본 계산기는 가장 범용적인 '원리금균등상환' 방식을 기준으로 실시간 연산됩니다. 중도상환수수료는 남은 기간에 따라 일할 계산되어 감소할 수 있으며, 신규 대출 시 발생하는 부대비용(인지세 등)에 따라 실정산 금액은 소폭 다를 수 있습니다.
